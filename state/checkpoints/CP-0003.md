# CP-0003: Operator ABI and strict plugin bootstrap

- `pypto-kernels` now exposes immutable, versioned framework-neutral contracts
  for tensor descriptors/pointers, mutation and result binding, problem and
  schedule identity, device fingerprinting, CUDA-event tuning, and complete
  artifact provenance.
- Adversarial tests reject mutable cache keys, bool/float FFI integers,
  misaligned pointers/workspaces, unsupported dtypes, non-writable results,
  mixed providers, and artifact-kind mismatches.
- `pypto-framework-plugins` verifies exact Torch/SGLang import provenance,
  installed entry-point uniqueness, strict compile configuration, current
  SGLang hook signatures, and all three GDN phases.
- SGLang/acceptance/GPU runner commands rehash the installed Torch tree and
  verify both plugin entry points before launch.
- The PyPTO compiler object-target patch remains uncommitted until its native
  and wheel build gates can run without competing with protected zcode jobs.
