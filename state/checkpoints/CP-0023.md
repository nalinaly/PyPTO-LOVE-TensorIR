# CP-0023: Accepted pointer-free CompileRequest v1

- PyPTO `09e014ceac2d2cac2f667d182bd7de8f0d0bd259` adds the first
  post-TargetInfo compiler transaction: an immutable, value-owned,
  pointer-free `CompileRequest` v1 data contract.
- The request owns program/target/compiler policy only. It requests Cubin,
  binds deterministic strict compilation and exact PyPTO/TensorIR/CUDA
  Tile/LLVM/CUDA-toolkit/tileiras identity, and contains no source region,
  route, schedule, model, pointer, stream, handle, produced bytes or runtime
  state.
- Canonical MessagePack serialization rejects missing/unknown/duplicate,
  noncanonical, trailing and malformed fields. A one-MiB input cap plus explicit
  array/map/string/bin/ext/depth limits reject allocation bombs before schema
  conversion.
- Separate canonical digests cover byte compile identity, loader-compatibility
  input and device/autotune identity. Physical identity, driver and total device
  capacity do not perturb compiled-byte identity; codegen-relevant SM/resource
  traits and exact toolchain identity do.
- Final CPU-only gates pass native CTest 2/2, Python TargetInfo/CompileRequest
  62/62 and warning-clean C++ syntax checks. A main-agent replay of both native
  executables and the 62 Python cases is bound by EV-0036 at run
  `pypto-20260824T090355Z-125028-c129ab`.
- Independent review found one P1 in default MessagePack allocation limits; the
  final commit fixes it and adds array32/map32/depth-bomb regressions. Final
  review reports no remaining blocker.
- This checkpoint does not implement `KernelBuildSpec`, link TensorIR/CUDA
  Tile, compile a kernel, create an Artifact/ArtifactCache/NvidiaExecutable,
  query or launch CUDA, modify framework plugins, or claim model/performance
  progress.
