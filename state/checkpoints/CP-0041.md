# CP-0041: Compile-free structured frontend build identity v1

- PyPTO `c4cf755b7ef2998cdfb7499a76b80b280bafdf2d`, tree
  `1be79708bffd09c4541f3f06c4a59b13ff0e1166`, adds the private
  `PreparedStructuredTensorIrCompilation` and final
  `FinalizeStructuredTensorIrBuildSpec` boundary after the CP-0039 emitter and
  CP-0040 standalone schedule identity.
- Preparation is the sole constructor path. It consumes `ir::ProgramPtr`,
  `CompileRequest` and `CanonicalSchedule`, calls the internal emitter, validates
  strict schedule/options, and owns exact source bytes plus ordered
  `Input0/Input1/Result0` metadata. TensorIR types and framework objects do not
  cross the seam.
- Five canonical MessagePack v1 projections now derive static specialization,
  explicit-empty symbolic specialization, argument ABI, result ABI and mutation
  ABI. The sixth source identity remains SHA-256 of the exact raw TensorIR bytes.
  Projection construction is private, domain-separated, lexically ordered and
  capped at 1 MiB.
- Finalization accepts the normalized real `ArtifactKernelAbi` object, never an
  arbitrary callable digest. It validates the pinned runtime/entry names,
  positional static descriptors, strides, counts, packing, tile sizes,
  one-dimensional static-grid form and target bounds, zero workspace, launch
  ABI and loader ABI before setting `callable_abi_digest` from the existing
  kernel-ABI identity.
- `nil` result alias records only the lack of HIR/SSA input-alias lineage. It is
  not runtime pointer non-overlap, `restrict`, allocation ownership or a Cubin
  proof. Producer descriptors also do not carry dtype or source roles; dtype is
  bound by exact source plus frontend projections and roles are positional.
- Prepared state is deliberately not a final BuildSpec or cache key. No
  provisional callable digest, rewritten key or compile-twice discovery route
  is allowed. A later public facade must compile once, finalize from that same
  producer result, construct the Artifact, and only then permit publication.
- Exact producer-reachable goldens cover FP32 `[8,8]`, tile 16, grid 4 and BF16
  `[128]`, tile 16, grid 8, including explicit versus implicit strides. Final
  BuildSpec digests are `2151a869...a0afa` and `062171a9...55a53`.
- Independent code/API and pinned-TensorIR reviews both report P0/P1/P2 = 0 and
  GO. The final backend-OFF adjacent native gate passes 4/4. A fresh clean-head
  backend-ON build completes and the expanded native gate passes 6/6,
  including the existing CPU TensorIR Artifact producer and fake-driver
  executable tests. Exact-DSO Python compiler/runtime suites pass 180/2 on and
  173/9 off.
- CP-0041 accepts only compile-free frontend identity derivation, strict schedule
  prevalidation and final BuildSpec construction from a supplied real-shaped
  ABI. It does not accept that the frontend invokes TensorIR, creates an
  Artifact, calls a GPU, exposes a Python API, uses ArtifactCache, or executes a
  framework/model.
