# CP-0008: Paged-attention ABI v1

- `pypto-kernels` is clean at
  `24ec7cf7c03a2f5e55ef240cde0ddddcc312aa40`.
- Prefill/extend and decode now share one framework-neutral paged-attention ABI
  with explicit query/new-K/new-V, mutable paged K/V cache, canonical indptr/page
  metadata, write slots, device-resident active counts and output.
- Descriptor and launch validators cover pitched Q/K/V split views, exact cache
  and metadata layouts, all tensor/workspace occupied-address aliasing, and
  unsigned 64-bit device ranges.
- A host-copy reference validator checks capacities, integer ranges, indptrs,
  append-complete page semantics, decode/prefill phase rules, unique tail writes
  and read-only radix page sharing. It does not read or attest device tensors.
- Inactive output capacity `[T:Cq]` is semantically BF16 zero for future graph
  buckets. Stable addresses are only a design target; capture/replay is not
  implemented.
- 61 tests plus 35 subtests, 1,000 randomized valid metadata cases, compileall,
  wheel build and clean import pass. Three independent reviews report no P0/P1.
- No numerical reference output, CUDA kernel/launch, SGLang adapter, graph
  replay, correctness or performance result is claimed.
- Heavy compiler/model work remained paused for zcode's protected TP2 vLLM/gem5
  lane; no external process was signalled.
