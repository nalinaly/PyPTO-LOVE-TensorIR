# CP-0028: Accepted runtime-free TensorIR producer-result primitive

- TensorIR `2677d1a9...` now returns a versioned in-memory
  `CudaTileCompiledArtifact` before reconstructing its legacy runtime kernel.
  It owns bytes, target/kind, entry names, full argument layout, packing/grid
  policy, workspace ABI, strict-option identity and exact assembler identity;
  it owns no CUDA, device, process, context, stream, pointer or runtime object.
- Strict Cubin compilation ignores ambient `TENSOR_IR_*` overrides, forbids
  fallback, requires canonical `tileiras` path/version/SHA, executes a
  verified non-writable copy, and rechecks its hash. TileIR is parsed fully by
  CUDA Tile; Cubin ELF headers/tables/segments/sections/text, CUDA OSABI/ABI and
  SM flags are bounded and validated.
- Static multi-tile grids, dynamic Flat ABI/runtime-grid metadata, malformed
  argument counts, packer bounds, truncated/header-only binaries, hostile
  environment, wrong producer SHA, explicit fallback, legacy reconstruction,
  and two identical SM120 Cubin compilations pass in the native gate.
- PyPTO `4789ae0f...` isolates TensorIR calls in a no-RTTI/no-exception bridge,
  verifies exact clean git revisions at configure time, isolates ON/OFF native
  outputs, and exports only `PyInit_pypto_core` from the single product DSO.
- Final native CTest is 5/5 and exact-current-DSO Python compiler tests are
  123/123. The final DSO SHA is `0b69023a...74a4b`, with no RPATH/RUNPATH and
  only the five standard runtime dependencies.
- This checkpoint is deliberately narrower than a PyPTO Artifact. It accepts
  an in-memory TensorIR producer result only; no canonical serialization,
  CompileRequest/KernelBuildSpec binding, cross-process transfer, cache,
  runtime, CUDA launch, wheel, operator, framework or model claim follows.

## Resume action

Implement the PyPTO-owned strict producer bridge and canonical Artifact v1.
The bridge must accept CompileRequest + KernelBuildSpec + canonical source,
cross-check every compiled toolchain identity, map the complete resolved
schedule, enforce Cubin-only/environment-off/fallback-off, and wrap the
TensorIR value in bounded canonical bytes with request/build-spec/producer/ABI
digests. Keep ArtifactCache and all CUDA runtime state in later transactions.
