# CP-0029: Accepted bounded canonical MessagePack foundation

- PyPTO `6ce17761cb26b6593ce8a6f0f8a82cb0cf251cc9` replaces the duplicate
  CompileRequest and KernelBuildSpec MessagePack helpers with one private,
  exception-enabled compiler codec. Their canonical serialization and rejection
  behavior remain covered by the exact source DSO suite.
- Before allocating a MessagePack object tree, a streaming visitor now bounds
  encoded payload, per-container items, aggregate container items, total decoded
  objects, nesting depth, non-binary bytes, BIN bytes and BIN field count. It
  rejects floats/extensions and converts parser overflows/truncation to PyPTO
  `ValueError` while preserving `std::bad_alloc`.
- The direct native matrix covers typed readers, embedded NUL/`0xff` BIN data,
  empty buffers, integer extrema, strict maps, N-1/N/N+1 size budgets, aggregate
  object/container amplification, depth, BIN/non-BIN accounting, duplicate BIN
  fields, trailing/truncated data, floats, normal EXT and exceptional EXT32.
- Post-commit backend-ON native tests pass 3/3 and the exact source DSO Python
  compiler suite passes 123/123. A fresh isolated backend-OFF build and native
  replay also pass 3/3; its DSO reports `compiled=false`, has no private NVIDIA
  targets/link inputs, no RPATH/RUNPATH and only the standard runtime closure.
- The root control regression passes 198 tests plus 98 subtests beside the
  protected CPU-only lane with no pause, external signal or NVIDIA compute PID.
- This checkpoint accepts only serialization infrastructure. It does not define
  Artifact v1, bind CompileRequest/KernelBuildSpec to produced bytes, map the
  strict TensorIR schedule, cross a producer DTO, publish a cache, load CUDA or
  claim any operator/framework/model behavior.
