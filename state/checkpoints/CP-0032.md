# CP-0032: Accepted compiler-owned ArtifactCache v1

- PyPTO `c087170444270cbe00f83e1fbf127ddcf3e33926` adds the only
  physical compiler-artifact cache. `ArtifactCache.lookup(request, build_spec)`
  returns a fully revalidated immutable Artifact or an exact miss;
  `publish(artifact, request, build_spec)` returns `Published` or
  `AlreadyPresent` without compiling, loading or launching anything.
- The cache key is exclusively the accepted precompile projection joining
  CompileRequest byte identity, complete KernelBuildSpec identity and exact
  producer-options identity. Device ordinal/UUID, loader compatibility,
  cache-root, model and framework identity do not enter the key.
- The caller supplies an existing absolute canonical non-root owner directory
  with exact mode `0700`. Linux rejects symlink components and unsafe writable
  ancestors, then creates the fixed owner-private namespace
  `pypto-nvidia-artifacts/v1/sha256/<prefix>/<digest>.artifact` through
  descriptor-relative operations.
- Lookup treats only `ENOENT` as a miss. It rejects wrong owner/mode/link/type,
  symlinks, FIFO/directory/special files, empty or greater-than-68-MiB files,
  read truncation/growth, metadata changes, noncanonical MessagePack,
  corruption and request/spec/provenance/key mismatch. Ordinary lookup never
  mutates or quarantines an entry.
- Publication round-trips the candidate, stages in the same shard with an
  exclusive random name, syncs and reads back exact bytes, sets and validates
  mode `0400`, syncs again, publishes with
  `renameat2(RENAME_NOREPLACE)`, and syncs the shard. A concurrent winner is
  accepted only after full validation and byte-for-byte canonical equality;
  corrupt or different winners are never replaced.
- Created directories use descriptor-bound no-follow permission changes,
  inode identity comparison, child `fsync`, then parent `fsync`. Cache handles
  are non-copyable/non-movable and creator-PID-bound; inherited use after fork
  is rejected and each process opens its own handle.
- V1 deliberately has no eviction, deletion, broad stale-temp cleanup,
  self-healing, remote cache, signature, compile-on-miss, lock around
  compilation or cache-wide quota. `ENOSPC` is an explicit availability error.
  The storage boundary is trusted-local and is not cryptographic origin
  authentication.
- A fresh backend-ON build passes native CTest 8/8, including real Cubin
  compilation, cache miss/publish/hit/idempotence, fork rejection and
  two-process `RENAME_NOREPLACE` arbitration. The exact product DSO compiler
  suite passes 137 tests with one expected backend-OFF skip.
- The accepted ON DSO SHA-256 is
  `d6c9729dff380335b9a9f0e3b581dc9f026b888b9cbf5b869a89888fe9df0c7b`.
  It has no RPATH/RUNPATH, only five standard runtime dependencies and only the
  version node plus Python init export; no private compiler/CUDA symbol leaks.
- A fresh backend-OFF build passes native 6/6 and the exact DSO compiler suite
  130 passed/8 skipped. Its DSO SHA-256 is
  `7edab542960eaa12d0354a169130724c558f8135c1fee4dd4302af5ff614c7e1`;
  it contains one cache implementation row, no private NVIDIA bridge source,
  and strict compilation remains fail-closed.
- Exact current seven-source provenance passes and rejects every wrong revision
  plus representative tracked, untracked and ignored drift. Ruff, Python
  source/stub Pyright, 1,133 header checks, 168 EN/ZH doc pairs/navigation and
  1,324 English-only checks pass. Independent API/security/final reviews report
  no remaining P0/P1. The isolated root control suite passes 198 tests plus 98
  subtests with CUDA hidden. EV-0045 binds the exact evidence.
- This checkpoint does not accept CUDA device/context/module/function state,
  support/resource legality, workspace allocation, current-stream launch,
  CUDA Graph, frontend-HIR lowering, operators, TorchInductor, SGLang, Qwen
  correctness/coverage, profiling or performance.

## Resume action

Implement a process/device/CUcontext-bound `NvidiaExecutable` as a separate P2
transaction. It must load only a fully validated cached/compiled Artifact,
resolve the exact entry, validate loader/resource/argument/grid/workspace ABI,
latch prewarm failures, own explicit load/unload and graph leases, and accept a
non-null raw current stream only at launch. Do not combine the first loader
transaction with framework registration, operator codegen or model execution.
