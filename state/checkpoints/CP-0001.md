# CP-0001: Multi-project source skeleton

- Authorized PyPTO is pinned on `feature/nvidia-sm120` at `e2d0f78...`.
- The standalone operator and framework-plugin repositories have independent,
  clean initial histories.
- Official PyTorch and SGLang are detached, pristine checkouts at the locked
  commits; PyTorch uses a documented sparse source surface and no submodules.
- The plugin scaffold rejects unsupported identities and refuses to label an
  unimplemented/default compute backend as PyPTO.
- The SGLang registration path terminates fail-closed because the upstream
  plugin loader intentionally swallows ordinary plugin exceptions.
- Heavy compilation, model copying, and server runs remain unstarted.
