# BL-0063: TensorIR reduction dtype is an accumulator contract

## Risk

Pinned TensorIR derives a built-in reduction's identity, accumulator tile and
combine arithmetic from the reduction input element type. A direct BF16
`reduce` therefore performs BF16 addition even if a higher-level PyPTO or
framework reduction is expected to accumulate in FP32. The dialect verifier
does not independently prove a wider accumulator contract, so successful
parsing or Cubin production would not expose this semantic loss.

Grid shape is a separate trap. Layout propagation normalizes a dense row-major
reduce-last graph to flattened outer rows plus one contracting mode. Its one explicit
schedule tile covers rows and a separately resolved contraction tile handles the width
inside the CTA. Flattening `M*N` for the launch would duplicate partial
reductions rather than implement one output per row.

## Lesson

Make accumulation precision explicit in canonical TensorIR. For BF16 row sum
or max, emit BF16-to-FP32 `convert`, an FP32 built-in `reduce`, and an
FP32-to-BF16 `convert` when the HIR result remains BF16. Bind those exact bytes
into the source digest and keep input/result metadata at the public BF16 ABI.

For the first reduction family, accept only static dense row-major
rank-1-through-32 reduce-last, keep-dim tensors. Let `rows=1` for rank 1 and the
checked product of all non-reduced extents otherwise. Require one positive
power-of-two row tile `T <= rows` and validate static grid
`{ceil(rows/T),1,1}`. Freeze that law with direct rank-1, rank-2 and rank-3
normalized-layout producer fixtures. Broadcast-back fusion, dynamic shapes and
non-contiguous layouts remain later contracts.

The configured contraction budget 128 is not always the actual tile. For
positive width `N`, pinned TensorIR selects `r=min(128, lowbit(N))` and loops
over `ceil(N/r)` chunks. Before calling the producer, require
`T*r <= 16,777,216`, CUDA Tile's element limit, and
`ceil(N/r) <= INT32_MAX`, because the lowering stores that loop bound as i32.
Odd widths select `r=1`; they may be legal but need separate performance
attention.
