# BL-0032: Diagnose redirects before choosing a process-local proxy route

The official NVIDIA `.com` URL redirects to `.cn` on this machine. Bypassing
only the first hostname silently returned the redirected transfer to the slow
proxy, while bypassing every proxy broke direct GitHub TLS. Keep proxy policy
child-local and route both NVIDIA hostnames directly while retaining the proxy
for GitHub/PyPI.

When changing a live run, signal only its verified PID/start-ticks/PGID. A TERM
may remove the group before the follow-up CONT verification; treat revalidation
failure as success only after the kernel proves the exact PGID is empty. Any
survivor or ambiguous scan returns 75 without another signal.
