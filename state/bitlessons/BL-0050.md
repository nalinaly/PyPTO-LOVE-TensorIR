# BL-0050: Prepare launch storage before capture and bind code to context, not stream

A persistent compiler Artifact is not a runnable handle. Reconstruct a fresh
process/device/CUcontext-bound executable, force lazy code loading, validate the
loaded function ABI/resources, and make every failure terminal for that object.
Never serialize or inherit module, function, context or stream handles.

The stream is invocation state, not executable identity. Require a real
caller-owned non-default stream on every launch, validate its context, and never
retain it. Allocate and validate argument slots, pointer arrays and runtime grid
in an immutable prepared packet before capture; make the packet itself a module
lifetime lease until asynchronous work is finished.

Fork safety includes destruction. Rejecting methods before an inherited mutex
is insufficient if the child can later destroy that mutex as the last shared
owner. A creator-PID custom deleter should intentionally leak the child's
copy-on-write inherited state until exec/_exit. A fresh child may create its own
runtime only if no parent CUDA Driver initialization occurred.

Test allocation claims with an allocation counter, but normalize under-aligned
aligned-new requests before `posix_memalign`; otherwise the test interposer can
break LLVM and misdiagnose its own fixture as product OOM.
