# BL-0038: A header-only toolkit target can still leak a runtime path

TensorIR dynamically resolves CUDA APIs and the unified PyPTO DSO had no CUDA
`DT_NEEDED` entry, yet linking the `CUDA::toolkit` umbrella target through a
static library injected `/usr/local/cuda-13.3/lib64` as an absolute RUNPATH.
That silently tied a future wheel to one producer-machine layout.

For an explicit `dlopen` boundary, export only the CUDA header requirement and
link only the platform dynamic-loader library. Audit both `DT_NEEDED` and
RPATH/RUNPATH on the final embedding DSO; checking direct dependencies alone
misses this class of leak.
