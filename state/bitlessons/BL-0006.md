# BL-0006: Block parent signals without blocking the child

Closing the `Popen` to metadata-publication race requires temporarily blocking
termination signals in the runner. POSIX children inherit that signal mask:
the first smoke test correctly verified and sent SIGTERM, but `/usr/bin/sleep`
kept it pending because the inherited mask still blocked the signal.

The safe transaction is:

1. install parent handlers and block SIGINT/SIGTERM/SIGHUP;
2. spawn the child into a new session;
3. restore the pre-block mask in the child before `exec`;
4. capture PID start ticks, PGID, run ID and workspace markers and atomically
   publish metadata;
5. restore the parent mask;
6. before any signal, re-read and verify all ownership fields.

Never escalate when a verified SIGTERM is ignored. Record the child as alive
and let the user or a later verified stop transaction decide what to do.
