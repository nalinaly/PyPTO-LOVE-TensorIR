# BL-0027: Distribution metadata does not prove editable runtime source

An editable distribution can retain the expected version and direct metadata
while its finder points at a different checkout that has advanced. Audit every
import carrier: executable `.pth`, direct URL, `sys.meta_path`, path hooks,
importer cache, loaded finder modules, imported module files and mapped native
libraries. Version equality and `pip check` are necessary but not source
ownership evidence.

For a build producer, freeze actual RECORD-owned bytes as well as versions.
Installer-rewritten console scripts are acceptable only as an exact,
entry-point-bound allowlist; every other declared RECORD hash and size must
match.
