# BL-0019: A benchmark schema must prevent internally consistent lies

Recomputing `speedup = baseline / candidate` is insufficient if workload,
correctness, bytes/FLOPS, provider or baseline identity came from arbitrary
caller fields. Derive what can be derived from typed config/descriptors and
closed runtime workload; leave metrics unavailable when no reviewed formula
exists. Reconstruct every digest-bearing public type during validation.

Candidate and baseline need symmetric evidence. Each has its own provider
resolution, artifact composition, correctness result, device environment,
compile phases and observed kernel trace. Only a separately reconstructed
comparison cohort may authorize speedup.
