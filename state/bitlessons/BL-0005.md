# BL-0005: Separate product failures from test-environment assumptions

A full-suite failure is not automatically a compiler regression. The first
PyPTO full run exposed four distinct boundaries:

- CPython debug source frames under `/usr/local/src/conda` are real callers,
  not PyPTO `src/` frames.
- Class source fallback must retain CPython's `__firstlineno__` when inspect
  fails, or duplicate nested class names select the wrong definition.
- Python 3.14 deferred annotations let the DSL emit its richer
  `ParserTypeError` where older eager evaluation can raise `NameError`.
- A scikit-build redirecting editable finder wins before a `PYTHONPATH`
  symlink, so a symlink-import probe must run from the fresh wheel gate.

Fix product behavior in production commits; fix portability and harness
assumptions in separate test commits. Then rerun the full suite before claiming
acceptance.
