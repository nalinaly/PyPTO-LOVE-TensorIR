# BL-0036: Build ID is metadata, not the only vendor-binary identity

NVIDIA's reviewed `ptxas`, `cuobjdump`, `nvdisasm`, and several CUPTI/NVPerf
ELFs are intentionally stripped and contain no GNU Build ID. Requiring a Build
ID universally rejects authentic pinned binaries without strengthening their
identity.

Keep the default strict: every ordinary ELF requires a valid Build ID. Permit
absence only for a closed path set whose complete-file SHA-256 is frozen from
the reviewed dependency overlay and rechecked against the wheel RECORD and
fresh extraction. Never turn missing Build ID into a generic warning.
