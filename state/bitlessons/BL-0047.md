# BL-0047: A strict compiler subprocess boundary includes its files and stdio

Hashing an assembler path is not enough. Execute a private copy of the verified
bytes, pass the exact toolkit root through a minimal environment, and bind that
environment policy into the pipeline identity. A copied CUDA tool may otherwise
fail even though its bytes and command line are correct because it cannot
rediscover its own toolkit root.

Closed host stdin/stdout/stderr is another embedding case, not an exotic test.
`open()` may return descriptors 0, 1 or 2; reserve every source descriptor above
stderr before ordered `dup2`, then close all other descriptors fail closed.

A directory walk is not a total-scratch quota when errors are silently skipped
or paths are reopened through symlinks. Use descriptor-relative
`openat`/`fstatat` with no-follow flags, restart only bounded live `ENOENT`
churn, reject permission/I/O errors immediately, and reject every post-exit
scan error. Preserve a fresh backend-ON real-producer test after each process
boundary change; a mock subprocess does not prove the pinned assembler path.
