# BL-0016: A green preflight is not a resource lease

Resource state can change between checkpointing and the next native command.
Here the heavy gate was green while packaging evidence was frozen, then zcode
started a new TP=2 vLLM/gem5 lane before the PyPTO full suite began. Rechecking
at the actual action boundary prevented interference.

Run preflight immediately before every heavy command, not once per session or
checkpoint. A later red result supersedes an earlier green observation without
invalidating the completed source-only work. Record the hold, send no signals,
and resume only after a fresh green result.
