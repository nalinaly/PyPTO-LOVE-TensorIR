# BL-0040: Serialized ABI counts must equal the writes they authorize

A total argument count is not sufficient validation. If dynamic size/stride
counts disagree with rank, uniform-signature policy or dynamic markers, the
packer can write more slots than the runtime allocated even though the total
field itself appears internally consistent.

Validate every derived count from primary metadata, bound every write, and
require the final packed count to equal the allocated count.
