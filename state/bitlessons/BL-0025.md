# BL-0025: A runtime kernel object is not a cacheable artifact

An API named `compile()` can still return only process state. TensorIR's
`IRuntimeKernel` hides argument packers and grid-computation objects, while the
frontend metadata needed to reconstruct them has no versioned serialization.
Caching its visible device bytes alone would produce an artifact that cannot be
safely loaded or launched in another process.

Freeze an explicit bytes-plus-metadata schema before implementing the cache.
Bind its key to CompileRequest, per-region KernelBuildSpec and exact
LLVM/tileiras producer identity. Derive actual artifact kind from bytes, keep
streams outside compile identity, and make module loading a process/device/
CUcontext-bound, separately leased prewarmed executable operation.
