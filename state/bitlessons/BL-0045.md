# BL-0045: Bound decoded structure before MessagePack allocates

Per-array, per-map and payload-byte limits do not bound aggregate decoded object
count: a modest nested MessagePack payload can still request a much larger zone.
For persistent compiler artifacts, run a no-object-tree streaming preflight that
counts total objects, declared child slots, depth, BIN fields/body bytes and
non-binary bytes before the ordinary allocating unpack.

Two adjacent lessons matter operationally:

- normalize parser exceptions at both streaming and allocating boundaries;
- do not make a header-only dependency PRIVATE merely because it has no DSO if
  existing public headers include it and downstream compilation needs its usage
  requirements.

Always prove the serialization source in both backend-ON and a fresh isolated
backend-OFF product so an internal compiler dependency cannot leak into the
disabled build.
