# BL-0044: Hash the executable bytes that are actually executed

Hashing a pathname before and after subprocess launch still leaves a pathname
replacement window. A different image can execute and the expected file can be
restored before the post-check.

Read and hash the producer once, materialize those verified bytes into a
private non-writable executable copy, run that copy for every producer query
and compilation, then recheck the copy before accepting output bytes.
