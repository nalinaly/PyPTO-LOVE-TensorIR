# BL-0041: One DSO file is not one isolated ELF namespace

Static LLVM archives initially produced one physical `pypto_core` file but
exported more than a thousand LLVM symbols. A process loading Triton with a
different LLVM revision could preempt those symbols despite the one-file
packaging audit.

Keep the LLVM ABI behind a no-RTTI/no-exception bridge, hide all archive
symbols, and use a version script that exports only the Python module entry.
