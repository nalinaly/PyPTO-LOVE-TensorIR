# BL-0034: Normalize extracted modes before freezing a tree hash

ZIP extraction uses the ambient umask, and even TAR directory creation can do
so before archived modes are applied. Hashing the resulting tree without a
mode policy makes the reviewed manifest machine-umask-specific.

Normalize all extracted and derived trees: directories 0755, regular files
0755 only when their archived/extracted execute bit is set and otherwise 0644,
while leaving symlinks untouched. The same full materialization fixture must
produce identical manifests under umasks 0022 and 0077 before freezing the
review anchor.
