# BL-0008: Graph capacity is part of operator semantics

A fixed-capacity output buffer is not fully specified by its active prefix.
If downstream graph nodes consume the padded tail, stale or non-finite values
can corrupt residual or collective computation. A graph-ready operator ABI
must explicitly define inactive output rows; paged-attention ABI v1 requires
BF16 zero.

Likewise, Radix cache sharing is safe only for read-only physical pages. Unique
write slots alone are insufficient: a page with any current write cannot be
shared across active requests without copy-on-write ownership.
