# BL-0021: Inventory the selected lifecycle, not a familiar legacy class

Pinning `MambaRadixCache` looked plausible, but the current hybrid-SSM registry
always selects `UnifiedRadixCache` and its `MambaComponent`. A source inventory
can be hash-perfect and still omit production if it starts from the wrong
implementation class.

Freeze the route-selection site as well as lifecycle methods. Label legacy
paths unselected, and inventory unified slot translation, checkpoint/donation
and reuse sites that affect generation ownership.
