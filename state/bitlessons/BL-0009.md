# BL-0009: Validate and consume one immutable snapshot

Validation is not a safety boundary if computation rereads a caller-controlled
mutable or stateful sequence. A second iteration can replace already-validated
page tables, write indices or active counts. Reference and adapter code must
snapshot once, derive capacities from that snapshot, validate it, and consume
only the same immutable bytes/values.

State references must also return the same storage domain they used for
computation. Rounding a BF16 prefix only on read while returning the original
unrounded Python value creates false prefill-to-decode continuity.
