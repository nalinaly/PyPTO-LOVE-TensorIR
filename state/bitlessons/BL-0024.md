# BL-0024: Derive reconnaissance facts; do not encode the expected answer

A pinned source hash detects drift, but a capability matrix is useful only when
its values are derived from the locked AST/text. Hard-coded occurrence counts
can make an audit green while proving nothing. Calculate call sites, registry
order, backend whitelists and explicit choice counts, then compare them with an
immutable expected contract and mutate synthetic sources in negative tests.

Keep implementation readiness in a separate immutable scope. Source truth such
as “CuTeDSL exists” or “no TileKernel exists” is not evidence that PyPTO codegen
or fallback rejection has been implemented.
