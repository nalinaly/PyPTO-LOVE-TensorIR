# BL-0069: Syntax checks do not validate immutable-container mutations

## Risk

A source-only review can parse each translation unit without instantiating the
exact test target and miss an operation that requires a deleted element
assignment operator. Here `ArtifactArgumentDescriptor` allowed construction and
move construction but deliberately deleted both assignments; replacing one
vector element therefore failed only in the real build.

## Lesson

Follow source review with a real exact-target build before accepting a compiler
family. When an immutable value inside a container must differ in a negative
fixture, reconstruct the complete container through allowed construction
rather than weakening immutability or changing the expected diagnostic. Verify
that each rebuilt descriptor preserves every unrelated field so the negative
case still isolates one invariant.
