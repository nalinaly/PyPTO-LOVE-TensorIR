# BL-0028: Review downloaded bytes before executing their tools

A URL and upstream version pin do not authenticate the bytes returned today.
Materialize dependencies into a hidden staging tree with archive/member/space
limits, hash both archives and expanded trees, and stop at an explicit
unreviewed state. Do not run `ptxas`, `FileCheck`, or any downloaded executable
until every archive digest and the canonical manifest digest are independently
reviewed and frozen in version-controlled source.

Promotion must consume that external source anchor, not calculate a new anchor
from the mutable manifest being promoted. Tool probes then run with no network,
minimal devices, read-only inputs, resource limits and absolute producer paths.
