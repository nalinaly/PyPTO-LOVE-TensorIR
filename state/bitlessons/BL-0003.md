# BL-0003: Strict plugins require launcher proof

SGLang intentionally logs and swallows ordinary entry-point load and hook
application exceptions. A plugin's own version check therefore cannot prove
that the plugin was discovered or applied.

Every SGLang, acceptance, and GPU benchmark launch must first:

1. rehash the locked project-local Torch runtime;
2. verify exactly one Torch and one SGLang PyPTO entry point from the expected
   distribution;
3. bind imported SGLang code to the clean locked checkout; and
4. stop before framework startup on any mismatch.
