# BL-0037: Directory-scoped includes do not make a library embeddable

TensorIR compiled successfully in its own CMake directory because that
directory injected LLVM and MLIR include paths globally. A parent target linked
to `NVTensorIR::Compiler` still failed when including its public `Compiler.h`:
the target exported TensorIR headers but not the MLIR/LLVM headers those public
headers directly include.

Every public CMake target must export the complete build-interface usage
requirements of its public headers. Test the target from a real parent project;
a standalone in-tree build cannot prove that contract.
