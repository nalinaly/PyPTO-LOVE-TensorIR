# BL-0039: Derive metadata before moving its source value

The first artifact seam moved `frontend.argLayout` into the result and only
then computed the static grid. The moved-from tile vector was empty, so every
static kernel silently received a one-CTA grid; the original one-tile test
could not expose the under-launch.

Compute all derived metadata before moving any source field, and include at
least one test whose correct value is not the default sentinel.
