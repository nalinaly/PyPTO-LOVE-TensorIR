# BL-0035: A green editable test is not current-source DSO evidence

An editable finder may load Python from the checkout while resolving its native
extension from a physically installed site-packages copy. After a late C++
refactor, the compiler tests stayed green because the old and new SHA-256
implementations were numerically equivalent, even though the selected DSO was
older than the source.

For native/Python contract acceptance, record the exact extension path and
SHA-256, compare build/source timestamps, and inspect expected/obsolete symbols.
If editable routing is ambiguous, explicitly bootstrap the one intended DSO and
package in `sys.modules`, then run the tests in that same process. Preserve any
green stale-DSO run as diagnostic evidence; do not promote it.
