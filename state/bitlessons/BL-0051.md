# BL-0051: Scope Ruff and disable its cache inside a source-provenance closure

## Symptom

A clean NVIDIA configure rejected vendored LLVM and PyPTO runtime repositories
because an earlier diagnostic `ruff check .` had written ignored `.ruff_cache`
files inside those nested Git trees.

## Cause

The PyPTO parent contains compiled nested repositories. Ruff recursively
entered them and created per-project caches even though their source findings
were not part of the intended PyPTO transaction. The strict provenance guard
correctly treats ignored build/tool state inside any compiled source repository
as source-closure drift.

## Rule

For a narrow PyPTO transaction, pass only the changed Python/stub paths and use
`ruff --no-cache`. Never run repository-wide Ruff across compiled vendor
gitlinks. Before configure, audit every compiled nested repository including
ignored files. If a diagnostic creates a cache, preserve the exact directory in
workspace quarantine and re-establish clean provenance before building.
