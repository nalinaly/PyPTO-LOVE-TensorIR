# BL-0059: Canonical fixtures must be reachable from the real producer

## Risk

A handcrafted `ArtifactKernelAbi` can satisfy local type and range validators
while remaining impossible for the pinned TensorIR pipeline to emit. Freezing
its digest would make a deterministic but dead compiler contract.

## Lesson

Every positive ABI golden must satisfy the producer's semantic legality rules,
not only PyPTO constructors. The first attempted small shapes paired `[2,3]`
and `[7]` with tile 16; TensorIR rejects those tiles because they exceed the
power-of-two bound of the normalized extent. The accepted fixtures instead use:

- FP32 `[8,8]`, tile 16, grid `{4,1,1}`;
- BF16 `[128]`, tile 16, grid `{8,1,1}`.

The first matches an already compiled TensorIR fixture and the second follows
the same pinned tile and flattened-grid law. Compile-free tests may leave
producer-owned `grid.x` uninterpreted, but their positive values must still be
reachable. The next transaction must add real-producer parity before promoting
this identity path to Artifact or GPU correctness.
