# BL-0004: Public headers determine CMake usage requirements

An object library is not merely a bag of object files: consumers compiling its
public headers need every transitive header search path those headers expose.
PyPTO's public `comm_layout.h` includes the runtime ABI header
`platform_comm/comm_context.h`, so `runtime/src/common` belongs in the object
target's `PUBLIC BUILD_INTERFACE`. Keeping it `PRIVATE` compiled the compiler
objects but failed late when nanobind compiled `modules/ir.cpp`.

Do not duplicate this include path in each binding consumer. Preserve the
dependency at the target that owns the public header contract, then validate
both editable and wheel builds.
