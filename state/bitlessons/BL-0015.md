# BL-0015: Scope control-repository test discovery explicitly

The control repository contains clean, full upstream checkouts beneath its
root. An unqualified `pytest` therefore discovers unrelated SGLang manual,
gateway and optional-dependency suites; their collection failures say nothing
about the control layer and can import code outside the intended validation
boundary. Run `python -m pytest -q tests` for root-control acceptance, then run
each nested project from its own repository with its own documented command.

Never solve accidental upstream collection by installing its optional stack or
editing upstream excludes. Preserve zero-diff sources and fix the invocation.
