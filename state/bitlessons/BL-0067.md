# BL-0067: Structured layouts can overflow when every physical tensor fits

## Risk

A matmul compiler can validate the dense element count of A, B and C
individually and still overflow an internal conceptual layout. TensorIR forms a
`B,M,N,K` view; its product can exceed signed 64-bit even when `B*M*K`,
`B*K*N`, and `B*M*N` each fit and all tile/grid/chunk checks pass.

An accepted example without the extra guard was `M=N=65536`,
`K=2147483648`: both inputs and the output fit signed 64-bit element counts,
but `M*N*K` is exactly `2^63`.

## Lesson

Validate every compiler-internal shape product, not only public buffer sizes.
Multiply positive factors incrementally with a division-form overflow check and
reject before emitting vendor IR. Keep boundary and first-overflow fixtures for
both unbatched and batched forms.

This is a semantic legality check, not a tuning limit or model-specific shape
specialization.
