# BL-0022: Inventory completeness is not executable readiness

A static source/AST audit only proves that expected upstream obligations still
exist. It cannot authorize registration or state transfer. Carry an immutable
`registration_ready=false` plus explicit prerequisite flags/order, and reject
weakened scope objects.

This prevents a future adapter from treating a green inventory as proof that
TargetInfo, current-stream execution, StateBundle leases or CUDA Graph safety
already exist.
