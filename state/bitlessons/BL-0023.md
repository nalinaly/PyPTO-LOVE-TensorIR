# BL-0023: A backend registry inventory must include every bypass

Finding `register_backend_for_device()` is not enough to design a zero-diff
Inductor plugin. Extern nodes bypass backend scheduling, foreach accepts a
hard-coded scheduler type set, multi-template can resolve to extern, MM/BMM
lowerings construct explicit external choices, and codecache consumes custom
registry state in its cache key.

Freeze producers, consumers and bypasses together. Until each unsafe route is
implemented by the new backend or rejected before scheduling, keep backend
registration false; an installed dispatcher alone does not prove strict
coverage.
