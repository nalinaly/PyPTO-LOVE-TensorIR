# BL-0042: Target output properties override global build isolation

Passing `CMAKE_LIBRARY_OUTPUT_DIRECTORY` did not isolate an OFF regression
build because the binding target set its own `LIBRARY_OUTPUT_DIRECTORY`; that
temporarily overwrote the accepted ON DSO in the source package.

Expose a target-owned absolute output option and verify both output paths and
hashes. A global CMake variable is not evidence when a target property wins.
