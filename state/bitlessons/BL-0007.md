# BL-0007: A provider string is not runtime coverage evidence

A strict coverage report is forgeable if an event can merely call itself
`pypto.*`, omit unreported kernels, change scope, or overwrite an earlier
failure. Coverage acceptance therefore needs three distinct boundaries:

1. a trusted collector owns scope and closed-world delivery;
2. the auditor reconciles the complete trace against an immutable manifest and
   artifact registry using exact digests and provenance;
3. report publication has single-run ownership, durable failure latching, and
   exact call/time numerators and denominators.

Even when all three pass, model correctness and timing-method validity remain
separate evidence gates.
