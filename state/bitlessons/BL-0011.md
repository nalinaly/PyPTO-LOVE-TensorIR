# BL-0011: Stateful correctness compares the whole transition

Matching only operator output can hide a corrupt recurrent or convolution
state that fails several decode steps later. A stateful reference gate must
compare output and every persistent state representation across equivalent
execution partitions: one-shot prefill, checkpoint-segmented prefill and
token-at-a-time decode.

Numerical references should also share one storage/rounding implementation.
Duplicating BF16, FP32 and snapshot helpers across operators invites quiet
semantic drift before any GPU kernel is written.
