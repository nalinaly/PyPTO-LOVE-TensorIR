PYPTO-NVIDIA-QWEN35-V1 IMPLEMENTATION MAP
=========================================

Status: checkout-grounded for PyPTO, PyTorch, and SGLang at CP-0001. TensorIR
and CUDA Tile remain pinned remote evidence until their PyPTO-internal source
checkouts are materialized.

Ownership
---------
projects/pypto
  Owns PyPTO frontend, compiler IR/pipelines, internal TensorIR/CUDA Tile,
  NVIDIA executable/runtime, generic fused-loop lowering and artifact cache.

projects/pypto-kernels
  Owns all handwritten high-performance operator families, schedule candidates,
  references, tests, benchmarks, tuning database and operator provenance.

projects/pypto-framework-plugins
  Owns pinned TorchInductor/SGLang registration, framework metadata adapters,
  strict compile/runtime auditing and compatibility guards. Contains no kernel
  algorithm.

upstream/pytorch and upstream/sglang
  Official, immutable reference checkouts. Any dirty state is an acceptance
  failure.

Known framework boundaries
--------------------------
- Torch OOT registration: torch/_inductor/codegen/common.py
- Torch scheduling/kernel/wrapper internals: torch/_inductor/codegen
- Torch selector limitation: register_backend_for_device has one process-global
  cuda slot; config.cuda_backend has no stable third-party named-backend registry
- Torch strict limitation: CSE/backend-name logic and template choices are
  commit-specific; the plugin must provide its own scheduling/CSE/wrapper
- SGLang plugin loader: python/sglang/srt/plugins
- SGLang attention registry: python/sglang/srt/layers/attention/attention_registry.py
- SGLang GDN dispatcher: python/sglang/srt/layers/attention/linear/gdn_backend.py
- SGLang Qwen3.5 model: python/sglang/srt/models/qwen3_5.py
- SGLang linear backend resolver:
  python/sglang/srt/layers/attention/linear/utils.py::resolve_linear_attn_backends
- SGLang Inductor entry:
  python/sglang/srt/compilation/compiler_interface.py::InductorAdaptor.compile
- SGLang current CUDA-graph metadata contract:
  init_forward_metadata_out_graph / init_forward_metadata_in_graph /
  init_cuda_graph_state plus breakable-graph capture/replay hooks
